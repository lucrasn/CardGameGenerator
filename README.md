# CardGameGenerator
ramework orientado a objetos desenvolvido em Java para modelagem e execução de jogos de cartas. A arquitetura baseia-se no princípio da Inversão de Controle (IoC), segregando os contratos de extensão (hot-spots) do motor de execução imutável (frozen-spots), com aplicação estrita de princípios SOLID e padrões de projeto GoF e GRASP.
